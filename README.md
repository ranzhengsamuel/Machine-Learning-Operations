# Machine-Learning-Operations
This is the repo for the course STT890 MLOps.
I used 2 models for predicting y. First, I used 1 variable, the highest correlated variable x4 to build a linear model. That model only achieved an R^2 score of 0.275. Then, I used 2 variables -- x4 and x2. This time, the model achieved an R^2 score of 0.513.
Then, I split both model into train/test split using 80/20 as a ratio. both the train and test results are not much different from the original linear model, for both models.
